# P01 语音速记首页（Hub）

> 应用打开即达。核心是语音/文字速记入口 + 时间线。P4 页面规约。
> 「状态」段七态会被 `tools/ixd2spec` 编译成 golden 测试义务。

## Section 1: 页面概述
应用首屏（Hub）。捕获优先：语音按钮最显眼，时间线次之，其余功能藏二级。

## Section 2: 布局结构
- 顶部：搜索框（自然语言检索）+ 设置入口
- 中部：时间线（最近笔记/任务/日程，按时间倒序）
- 底部：语音速记按钮（长按录音，FAB 式）+ 文字输入入口

## Section 3: 组件清单
- C01 VoiceButton（语音速记按钮，长按录音）
- C02 TextCapture（文字输入，点击展开）
- C03 TimelineItem（时间线条目）
- C04 SearchBar（自然语言检索）

## Section 4: 交互行为
- **C01 VoiceButton**：
  - 长按 → `onStart` → 录音态（波纹动画）
  - 松手 → `onSubmit` → 提交转写（满足 REQ-CAP-VOICE）
  - 录音中上滑 → `onCancel` → 取消、不留存（REQ-CAP-VOICE-c）
- **C02 TextCapture**：点击展开输入框，回车提交
- **C04 SearchBar**：一句话提问 → 检索结果附来源引用（REQ-RET-NLSEARCH）

## Section 5: 状态机（七态）
- 默认: 显示语音按钮 + 时间线
- 加载: 提交后转写/结构化中，骨架屏
- 空数据: 空插画 + "长按说一句试试"
- 报错: 转写失败 + 重试按钮
- 无权限: 麦克风权限被拒 + "去设置开启"
- 离线: 离线提示 + 录音排队、联网补传（REQ-CAP-VOICE-OFFLINE）
- 超长文本: 录音超长，提示分段

## Section 6: 动效
- 长按→录音：波纹扩散 200ms（micro）
- 录音→提交：波纹收拢 + 卡片上滑 300ms（page）
- 转写中：骨架屏闪烁

## Section 7: 数据策略
- 默认：本地时间线即时显示
- 离线：录音本地排队，联网后自动补传
- 检索：离线降级为本地关键词，联网恢复语义检索
