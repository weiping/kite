# Phase 3: Kite 用户流

## 流 1：语音速记（核心任务）

```mermaid
flowchart TD
  A[打开应用 P01] --> B{长按语音按钮}
  B -->|是| C[录音中 波纹动画]
  B -->|否| D[文字输入 TextCapture]
  C -->|松手| E[提交转写]
  C -->|上滑| F[取消 不留存]
  D --> E
  E --> G{联网?}
  G -->|是| H[转写+结构化]
  G -->|否| I[本地排队]
  I --> J[联网后自动补传]
  H --> K[入库 时间线]
  J --> K
```

### Step Table
| 步骤 | 动作 | 页面状态 | 预估耗时 |
| --- | --- | --- | --- |
| 1 | 长按语音按钮 | 录音中（波纹） | 1s（触发） |
| 2 | 松手 | 转写中（骨架屏） | 2-3s |
| 3 | 转写完成 | 入库（时间线新增） | — |

## 流 2：检索与追问

```mermaid
flowchart TD
  A[P01 搜索框] --> B[输入一句话提问]
  B --> C{联网?}
  C -->|是| D[语义检索]
  C -->|否| E[本地关键词降级]
  D --> F[结果列表 带来源引用]
  E --> F
  F --> G{点击追问?}
  G -->|是| H[P06 追问对话]
  G -->|否| I[P02 笔记详情]
```

## 关键决策点

| 决策点 | 条件 | 分支 |
| --- | --- | --- |
| DP1 联网状态 | 离线 | 速记走排队（REQ-CAP-VOICE-OFFLINE）；检索降级关键词 |
| DP2 麦克风权限 | 未授权 | 引导去设置（P07），不静默失败 |
| DP3 模型就绪 | whisper 未下载 | 录音排队，联网补模型再转写 |
