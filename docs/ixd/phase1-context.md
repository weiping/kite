# Phase 1: Kite 产品上下文

## Product Design Brief
Kite 是个人 AI 助理，核心命题：「最低心智负担地捕捉、组织、找回自己的想法」。
语音/文字速记 → 自动结构化（笔记/任务/日程）→ 本地优先离线可写 → 自然语言检索追问。

## Product Design Summary
- 双端：Flutter（iOS / Android），后续桌面 / Web
- 后端：Python（Agent 编排层 + API Server）
- 本地优先：核心路径离线可用，数据属用户（charter 第1、3条）
- AI 可追溯：生成内容标来源、不冒充确定（charter 第4条）

## Design Challenges
1. **捕获零摩擦（≤3s）vs 功能丰富** → 速记优先，UI 必须极简，功能藏在二级
2. **离线优先 vs AI 算力**（转写/检索）→ 端侧模型 + 离线降级，不让无网阻断捕获
3. **AI 可追溯 vs 流畅不打断** → 轻量来源标注（非阻塞），不确定标置信
4. **反注意力经济**（charter 第2、5条）→ 拒绝信息流/红点/留存推送的设计模式

## Design Principles
1. **捕获优先**：任何时刻 ≤3s 开始记；语音按钮永远最显眼
2. **安静**：无推送、无信息流、无未读红点
3. **可追溯不冒充**：AI 输出标来源与置信，不确定就说"未找到"
4. **离线即默认**：无网时核心可用，不报错、排队
5. **数据可见可控**：本地优先，一键导出/删除

## Design References
- 速记交互：Flomo（极简入口）、闪念胶囊（长按速记）
- 本地优先：Obsidian / Logseq（数据属用户）
- AI 可追溯：Perplexity（来源引用）
- 反例（刻意不学）：短视频信息流、留存推送、社交互动红点
