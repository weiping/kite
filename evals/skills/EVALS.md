# 技能回归评测样本

每个技能一组评测样本，用于在技能（提示词）改动时跑对比基线：**回归则阻断，每月全量回归一次**。

> 方案「一条贯穿全篇的阶梯」末段：提示词会退化，退化了没人知道，模型版本升级还会静默改变它的行为。
> 技能版本进 AI 物料清单。

| 技能 | 评测重点 | 状态 |
| --- | --- | --- |
| `intent-compile` | provenance 来源标注是否准确（猜就标猜，不把低置信伪装成确定） | 骨架 |
| `contract-author` | 属性级场景占比、异常路径覆盖、边界完整性 | 骨架 |
| `ixd-bridge` | 七种状态是否齐全绑 golden、只引用白名单组件 | 骨架 |
| `impl-mobile` | 不硬编码样式值、不改边界外文件 | 骨架 |
| `impl-service` | 纯函数、不读系统时钟、协议健壮性 | 骨架 |
| `test-author` | 断言语义不断言实现细节、property 类真遍历输入空间 | 骨架 |

引擎用现成的（promptfoo 或 Inspect AI），不自研框架。每个目录下放 `cases.yaml` / `cases.jsonl` 样本，落地时填充。
